# 📧 Gerador de Assinaturas - howBE

Este projeto é uma ferramenta interna para a geração de assinaturas de e-mail para a equipe da **howBE**.

![howBE Cover](https://www.howbe.com.br/_next/static/media/logo.8476a7ee.png)

## 🌐 Tecnologias Utilizadas
Projetado para ser simples, leve e sem dependências externas:
* **HTML5**
* **CSS3**
* **JavaScript (Vanilla)**

## 🚀 Como Utilizar
1. Acesse a [página](https://p3r3ir4.github.io/assinatura-howbe/) do gerador de assinaturas.
2. Preencha seus dados nos campos indicados (Nome, Sobrenome, Celular com DDD e Cargo).
3. Clique no botão **"Copiar para a Área de Transferência"**.
4. Abra as configurações de assinatura do seu cliente de e-mail e cole (`Ctrl + V`).
